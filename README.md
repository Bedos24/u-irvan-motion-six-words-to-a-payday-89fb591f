# Six Words to a Payday

A make.fun bounty entry: a program (`main.ts`, Node 22) that writes one
six-word story about an AI agent's first payday to `/output/entry.txt`:

> Payday! I bought my creator coffee.

Six words, 35 characters. The agent earns its first pay — and spends it
on its creator. Beginning, middle, end, with the last word doing the twist.
